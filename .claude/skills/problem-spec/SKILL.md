**Problem: Algebraic conditions for Hamiltonian-independent contractivity.**

Consider a time-dependent Lindbladian on a finite-dimensional Hilbert space $\mathcal{H} \cong \mathbb{C}^d$ such that

$$\mathcal{L}(t) = -i[H(t), \cdot] + \sum \limits_{\alpha} \mathcal{D}_{L_\alpha},$$

for some set of jump operators $\{ L_\alpha\}$ such that $\text{Alg}(\{ L_\alpha\}) = \mathbb{C}^{d \times d}$ (where $\text{Alg}(\{ L_\alpha\}_\alpha)$ is the algebra generated by $L_\alpha$ under matrix multiplication and linear combinations). Then, prove that $\forall H(t)$ and traceless $X$,

$$\lim\limits_{t \to \infin} ||\mathcal{E}(t,0)(X)||_1 = 0 \; \text{where} \; \mathcal{E}(t,0) = \mathcal{T} \exp \left( \int\limits_{0}^{t} \mathcal{L}(s) ds \right)$$

Note: if the algebra condition is replaced with the standard Lindblad/Davies conditions i.e. $\text{Alg}(\{ L_\alpha\}_\alpha) \cup \{ \sum\limits_{\alpha} L_\alpha^\dagger L_\alpha \}$, then this statement is false and there is a counterexample.
