Step 1: State Audit

Step 2: Script Implementation (phase_N.py)
- All code should be compatible with the `3p12` conda environment.
- In phase_[N]/ write a standalone Python script named phase_[N].py based on the task_description for that phase.

Step 3: Performance Audit - IMPORTANT
- The code must be EFFICIENT in time, and results MUST CONVERGE in a reasonable time (<2 hours maximum).
- Explicitly enumerate all independent tasks in a comment at the top of the file. All independent tasks (e.g., fitting different models, processing different segments, running different configurations) must be dispatched concurrently using ProcessPoolExecutor or multiprocessing.Pool to minimize wall time. A sequential for-loop over independent tasks is never acceptable.
- Before finalizing any depth or iteration parameters (e.g., number of steps, restarts, iterations, samples, or similar), you must first run a minimal timing probe: execute one representative unit of work (one task, one model, etc.) and measure its wall time. From that measurement, determine if the full computation will take less than 2 hours. Be conservative and assume tasks will take longer than you expect. Do not use plan-spec values blindly — treat them as upper bounds, not targets.
- Reduce the basis size, number of time steps, iterations, or similar parameters in order to reduce the time complexity. It's essential that the computation CONVERGES.
- You may edit the Python tools (`tools/`) to support vectorization,multithreading, etc. You must take a note if you make any changes.

- You must check your code before running it. Make sure there are no variable name mismatches or other issues that would cause your code to crash after results converge.
- Run the script using the terminal execution tool.
- If the script is taking longer than 2 HOURS you MUST kill the process and review the code. Refer back to the Performance Audit (Step 3) and make changes.

    - Figures: All diagnostic plots required by the PLAN.md (e.g. spectra, phase diagrams, parameter sweeps). ENSURE at least one figure directly compares the key predictions of all models, for ease of human interpretation.
